# 第五次作业进阶 B：基于代价地图的 A* 路径规划

这是普通 C++ 命令行工程，不依赖 ROS2、Nav2 或其他路径规划库。

## 构建与运行

```bash
cmake -S . -B build
cmake --build build -j
./build/path_planner maps/map_public.txt 0 0 9 7 0
ctest --test-dir build --output-on-failure
```

运行参数依次为：地图文件、起点 x、起点 y、终点 x、终点 y、机器人半径。

## 实现内容

- 严格读取并校验地图尺寸、栅格数量和 0/1 取值。
- 使用欧氏距离对障碍物膨胀，保证机器人半径安全距离。
- A* 支持上下左右和四个斜向，共八个方向。
- 直线代价为 10，斜线代价为 14。
- 斜向移动时检查两个正交相邻格，禁止斜穿墙角。
- 使用八方向的 octile 距离作为不高估的启发函数。
- 通过优先队列处理重复节点，弹出时丢弃过期条目，复杂度为 `O(V log V)`。
- 使用超级覆盖栅格遍历进行直连碰撞检测，简化路径不会穿过障碍物或斜穿墙角。

## 输出

成功时输出 `PATH_FOUND`、总代价、简化路径坐标和文本地图。无路时输出 `NO_PATH`。起点或终点非法时输出错误并返回非零状态。

## 提交问题说明

优先队列允许同一节点多次入队，因为发现更短路径时会再次入队。节点出队时比较队列条目的 `g` 与当前最佳 `g_score`，不一致的旧条目直接跳过，不影响正确性。

启发函数不能高估实际剩余代价，否则 A* 可能提前选择看似更优但实际更差的路径，无法保证最低代价。八方向移动的 octile 距离满足这一条件。

两点直连检查使用超级覆盖栅格遍历，检查线段接触的所有栅格；每次斜向跨格还检查两个正交相邻格，因此原始路径和简化路径都不能斜穿墙角。
