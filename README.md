# 第二次作业：理论理解题

## 1. 小陀螺为什么会给传统自瞄带来巨大挑战？

小陀螺是指对方机器人底盘快速旋转，而装甲板随底盘绕机器人中心不断改变朝向和位置的运动状态。传统自瞄通常将目标近似为短时间内做平移、速度变化较小的物体，再根据上一帧或前几帧的位置预测下一帧位置。

但小陀螺运动会使装甲板的图像位置、朝向、可见面积和深度周期性快速变化：同一块装甲板可能很快转到侧面甚至完全不可见，下一时刻又可能是另一块装甲板进入视野。因此，前后帧中检测到的目标未必是同一个装甲板；只按相邻两帧的位置差估计速度，得到的速度方向和大小也会不断跳变。再加上云台、子弹飞行和系统通信均有延迟，等弹丸到达时装甲板已转到别处。要稳定命中，需要估计旋转中心、半径、角速度和相位等运动模型，而不能只做普通的线性平移预测。

## 2. 图像分类和目标检测的核心区别

图像分类回答的是“这张图里主要是什么”。模型输入一整张图，输出一个或多个类别及其概率，例如“这是一辆车”或“图中有装甲板”。分类结果通常不关心物体具体在图中的哪个位置，也不能区分同类物体有几个。

目标检测不仅要回答“有什么”，还要回答“在哪里”。它会为每个目标输出类别、置信度和边界框（或中心点、宽高），例如同时给出两块装甲板各自的位置。因此，检测任务的标注和输出都包含空间位置信息，适合后续的跟踪、距离解算和瞄准；分类更适合整图内容判断。

## 3. 相机畸变、内参标定及其对测距精度的影响

理想的小孔相机模型中，空间直线投影到图像中仍是直线，像素坐标与视线方向之间有确定的几何关系。但实际工业镜头会因镜片形状和装配误差产生畸变。最常见的是径向畸变：画面边缘向外鼓起称桶形畸变，向内收缩称枕形畸变；还可能有切向畸变，即镜头与成像平面不完全平行造成的偏移。

内参标定是用已知尺寸的标定板拍摄多张图像，估计相机内参矩阵和畸变系数的过程。内参矩阵主要包含焦距、主点位置等参数，畸变系数用于把畸变像素坐标校正到更符合小孔模型的位置。

测距或 PnP 解算依赖“已知物体实际尺寸”和“图像中角点像素位置”的对应关系。若未标定，像素位置本身带有畸变，尤其目标在图像边缘时，角点间距和视线方向会被错误解释。算法会把这种二维误差当作目标姿态或距离的变化，从而造成距离、横向位置和姿态估计偏差；距离越远、目标越小，少量像素误差带来的相对距离误差通常越明显。

## 4. solvePnP 的输入及二维角点误差为何会导致三维位置抖动

`solvePnP` 用于求解目标相对于相机的位姿。调用时的核心输入包括：

- 目标特征点在目标自身坐标系中的三维坐标，例如装甲板四个角点的实际尺寸坐标；
- 这些特征点在图像中的二维像素坐标；
- 相机内参矩阵；
- 畸变系数。

在有初始位姿或需要选择算法时，还可提供旋转、平移初值及 PnP 求解方法。输出是旋转向量 `rvec` 和平移向量 `tvec`，其中 `tvec` 可理解为目标在相机坐标系下的三维位置。

PnP 本质上是在寻找一组位姿，使已知三维点投影后尽量贴合检测到的二维点。角点检测受图像噪声、曝光、运动模糊、遮挡和边框拟合影响，常常会有几个像素的误差。投影是非线性的，而且深度主要由目标在图像中的尺度变化推断：目标较远时，装甲板在图中很小，角点间距的微小变化就可能对应较大的深度变化。因此二维角点的随机抖动会被反投影并放大为三维位置，特别是距离方向的抖动；错误的内参或畸变参数还会进一步放大这种现象。

## 5. 为什么不能只由相邻两帧估计速度？卡尔曼滤波有什么作用？

只使用相邻两帧的位置差除以时间间隔得到的速度，完全依赖两次测量。视觉检测的位置会有噪声，帧间隔也可能不稳定；当目标被短暂遮挡、检测框跳动或误匹配时，速度会出现很大的瞬时误差。该误差再用于预测，会直接使瞄准点跳动。对于加速、转弯或小陀螺等运动，两个点也不足以描述真实运动趋势。

卡尔曼滤波会维护目标的状态，例如位置和速度，以及状态的不确定度。每一帧先根据运动模型由上一时刻预测当前状态，再用当前测量结果修正预测。测量较可靠时更信任观测；测量噪声较大或暂时丢失时更依赖模型预测。这样能综合多帧信息，平滑位置和速度估计，并在短暂丢失目标时继续给出合理预测，从而为考虑弹道和系统延迟的提前量计算提供更稳定的输入。
